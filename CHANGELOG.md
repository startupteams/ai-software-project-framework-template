# Changelog

All notable changes to this framework are recorded here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-11-04

First public release.

### Added

- Markdown-first project skeleton: `REQUIREMENTS.md`, `SPRINT.md`, `FEATURE_ROADMAP.md`, `FUTURE_WORK.md`, `docs/ARCHITECTURE.md`.
- `AGENTS.md` operating rules for AI coding agents, with `CLAUDE.md` pointing Claude Code at it.
- ADR and TDR templates, ADR-0001 (Markdown and Mermaid), and TDR-0001 to TDR-0003 (backlog and CI policies).
- Level 3 agent-readiness checklist and proportional CI validation policy.
- Pull request template and a lightweight documentation check workflow.
- MIT license.
